# Changelog

All notable changes to Copyloom will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases will use semantic versioning once public compatibility begins.

## [Unreleased]

### Added

- Phase 0 product, architecture, database, permission and threat-model research.
- Copyloom project identity and Apache-2.0 license.
- Native sandboxed macOS menu-bar host with no clipboard access at launch.
- Swift package modules for domain types, structured search parsing and GRDB-backed storage.
- Minimal accepted-text migration with versioned hashing and external-content FTS5.
- On-disk persistence/search integration tests.
- Explicit opt-in text/link clipboard monitoring with pause and ignore-next-copy controls.
- Pre-persistence concealed/transient/vendor marker checks, ignored-app checks, size limits, and local sensitive-content detection.
- Source application provenance aggregation and source-aware FTS/filter search.
- A labeled, accessibility-identifiable Copyloom menu-bar item and diagnostic script.
- Native Quick Paste panel with global `⌃⌘V`, live FTS5 search, keyboard navigation, copy, pin, delete, use-count tracking, and copy-loop suppression.
- Previous-application automatic paste with contextual Accessibility explanation, target validation, activation confirmation, and copy-only fallback.
- Fixed retained-target loss caused by weak `NSRunningApplication` storage and added an explicit menu action for automatic-paste permission setup.
- Development launcher now terminates every stale Copyloom process and verifies exactly one instance, preventing duplicate menu icons and old-process hotkey ownership.
- Compact icon-only menu-bar presentation retaining the `Copyloom` accessibility label.
- Explicit Quick Paste footer labels distinguishing Return paste and Command-Return copy-only; the non-distinct plain-paste hint is hidden until rich representations exist.
- Versioned capture settings stored outside history with fail-closed unknown/corrupt handling and legacy migration.
- Time-based retention deleting unpinned/unfavorited clips older than 30 days with FTS cleanup, automatic on launch plus manual menu action.
- Clip favorite action supporting retention exemption and future Library Favorites.
- Menu-bar diagnostics showing ignored-app count, retention window, running app path, and Reveal in Finder to disambiguate ad-hoc development TCC identity.
- Native Settings window with Ignored Apps (add/remove/reset plus running-app picker), History retention stepper with manual cleanup, and Permissions status with running-app identity.
- Image attachment storage foundation: migration 004, content-addressed `Attachments/v1` files, tombstone-aware file GC, `type:image` search. Capture not yet wired.
- Image capture path with stubbed fail-closed privacy gate: pasteboard flavor gate (text wins on mixed snapshots), byte/pixel ceilings, preflight timeout race, 12 new policy/service tests. Vision OCR gate stays slice 3; the default gate refuses all images.
- Vision privacy gate: dimensions-only decode, in-memory OCR with accurate recognition and language correction off, existing sensitive detector over OCR text, once-guarded Vision continuation, 6 new gate tests including live-Vision blank-image plumbing.
- Image capture activation: Vision gate wired into the service, Quick Paste lazy thumbnails, image paste-back with loop-suppression markers, startup orphan reconciliation. A03 manual evidence pending.
- OCR-tolerant PEM refusal: live screenshots mangle dash runs past exact patterns, so the gate adds an OCR-only tolerant header check; prose about keys still passes. Evidence in `docs/validation/m2-images.md`.
- Search benchmark runner + first 100k-record report: 10 of 13 classes pass (most <1 ms); app-filter pre-resolution and pinned timeline walks fixed from the numbers. Giant-match `bm25` sorts stay open as a product decision. Evidence in `docs/validation/m2-benchmarks.md`.
- M2 close-out: panel warm-open telemetry (~48 ms + 1 frame), idle cost (~0% CPU, 36 MB), full 17-item acceptance sign-off with deferred list. M2 declared complete.
- Library shell (M3 slice 1): `LibraryFeature` module with five backed sections, list/cards densities, inspector with copy/pin/favorite/delete, favorite parity in Quick Paste (`⌘F` + row star). Global `⌃⌘L` via a second Carbon registration with pressed-ID dispatch; Library lives in an AppKit window (a menu-tree notification observer misses hotkeys fired with the menu closed).
- Organization (M3 slice 3): migration 005, collections/tags/saved-queries CRUD, tag search filter, sidebar groups with sheets and context menus, tag editor, drag into collections and text drag-out, re-parsed Smart Collections.
- Kind detection + type sections (M3 slice 2): capture-time code/color/file classification with prose-safe conservative rules, Files/Code/Colors sections, mono code preview, hex swatches, file reveal. Finder copies persist as path references via `public.file-url` priority (live probe). No highlighting dependency (Splash is Swift-only).
- Searchable OCR (M3 slice 4): migration 006 (`ocr` column + FTS rebuild + `image_ocr_jobs` queue), serial background OCR with crash-resumable pending/indexed/withheld states, quarantine UX (withheld banner + one-tap delete, pixels stay, never content-searchable), `has:ocr` filter, 0.71 s FTS rebuild at 100k rows. Evidence in `docs/validation/m3-ocr.md`; owner live evidence pending.
- Transforms (M3 slice 5): pure `ClipTransforms` registry with JSON pretty/minify/validate, case, trim/collapse-whitespace, URL and Base64 encode/decode, and HEX/RGB/HSL color conversion. JSON output reformats whitespace at the token level so key order and number text (`1.10`, 20-digit integers) survive. Library inspector gets a Transform menu with preview, Copy result and Save as clip; saving runs the capture text gate (size, sensitive detector, kind) and an unwired model refuses to save. A scale test pins pretty-printing to linear time (a quadratic append took ~92 s on a 5 MiB clip).
- Design refresh: Library list column widened (it was ~200 pt, wrapping every row), compact ages (`11m`) replace "11 min, 9 secs" and no longer re-render every row each second, Quick Paste now shares the Library's kind icons and color swatches, image clips get a real downsampled preview with dimensions and size (the inspector previously showed a 28 pt badge), inspector restructured around the clip (kind, source, age, favorite/pin toggles, content card, details, tags, actions), unambiguous dates, long text capped in the inspector, equal-height card grid, developer diagnostics removed from the menu (still in Settings → Permissions).
- Fixed a launch crash: the Library window was built inside `AppModel.init`, and restoring a saved window frame that differed from the default forced a nested SwiftUI layout. The window is now created on first use.
- DEBUG-only preview mode (`COPYLOOM_PREVIEW=1`): runs against a separate synthetic database, never starts capture, and renders the main surfaces to light/dark PNGs in-process. See `docs/testing.md`.
- Archive format v1 core (M3 slice 6a): new pure `ClipArchive` module with the record types, manifest, writer, verifier and reader for the portable export format designed in `docs/archive-format.md`. Paths are a three-shape whitelist (not sanitized); archives are written to `.partial` and renamed only after the manifest, so an interrupted export is never mistaken for a finished one; verification is read-only and checks size, SHA-256, archive digest, counts, symlinks and limits before any record is decoded. Bad records are reported per line without hiding good ones. Not wired to storage or UI yet (slices 6b/6c).
- Export core (M3 slice 6b, part 1): `ArchiveExporter` plus a database-backed source. The privacy gate is a required argument (no way to build an exporter without one); text the gate refuses and images whose OCR text was withheld are skipped and only counted (their pixels are never even read); a missing or corrupt attachment skips that clip only; collections list only exported clips; a failure or cancellation leaves no archive and no `.partial` folder. The source reads from one database snapshot in 500-clip keyset pages. Fixed a timestamp bug found on the way: the ISO formatter truncated, so many millisecond values came back one ms early. Not wired to the UI yet.
- Export Library (M3 slice 6b, UI): Library toolbar **··· → Export Library…** explains that the export is unencrypted and what is left out, lets you pick a folder, writes `Copyloom Export <date>` (never overwriting), shows progress with a Cancel button, and reports counts plus Reveal in Finder. Adds the sandbox entitlement `com.apple.security.files.user-selected.read-write` (documented in `docs/permissions.md`). A model built without an exporter refuses. The DEBUG preview run now also performs a real export through the production wiring and verifies it, including that a planted fake credential is not in the archive.
- Import Library (M3 slice 6c): Library toolbar **··· → Import Library…** checks an export folder (nothing is written), shows what importing would do, and only then imports in batches with progress and Cancel. Text passes the capture text gate and images pass the capture image gate (the Vision privacy preflight included), now one shared `ImageAcceptanceGate`; kinds, hashes, image sizes and OCR text are re-derived rather than trusted; records that break a bound are rejected one by one. Merge never overwrites: an existing clip only gains a pin, favorite, earlier creation time, tags and collection membership, and importing the same archive twice changes nothing (tested over every table and file). A clip whose UUID is taken by different content gets a new one. The plan warns, with a count, when imported clips are older than the history window and would be deleted by the next cleanup. Cancelling leaves a valid partial import that re-running completes. The reader now streams through one pull-based line source, and `THREAT_MODEL.md` gains T14.
- Fixed the reader scale test, which failed on hosted CodeQL (4.3 s traced against a 3 s bound) since the FIFO fix landed; the bound is 6 s, still below the quadratic reader it guards against.
- Reproducible local/CI scripts and open-source contribution files.
